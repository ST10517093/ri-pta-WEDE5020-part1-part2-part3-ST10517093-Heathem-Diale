
# Halwas African Restaurant Website

## Project Title
Halwas African Restaurant Website – WED5020POE

## Project Overview
A responsive multi-page website for Halwas African Restaurant in Pretoria Central. The website presents the organisation, menu, catering services, gallery, reservations and contact information.

## Website Goals and Objectives
- Improve online visibility.
- Make menu, location and contact information easy to access.
- Increase reservation and catering enquiries.
- Provide a mobile-friendly user experience.
- Demonstrate HTML5 structure, CSS3 styling and JavaScript interaction.

## Pages / Sitemap
- index.html – Home
- about.html – About Us
- menu.html – Menu
- catering.html – Catering
- gallery.html – Gallery
- reservations.html – Reservations
- contact.html – Contact
